# Παπαδήμας Ιωάννης — Ψυχολόγος | δοκιμαστική έκδοση

Στατική προεπισκόπηση του site, για να το δει ο πελάτης πριν βγει στον αέρα.

> **Δοκιμαστικό.** Δεν είναι το τελικό site. Οι σελίδες «Πολιτική Απορρήτου»
> και «Όροι Χρήσης» είναι σχέδια και θέλουν νομικό έλεγχο. Όλες οι σελίδες
> φέρουν `noindex`, ώστε να μην εμφανιστούν στις μηχανές αναζήτησης.

## Τι υπάρχει εδώ

```
index.html                 Η αρχική σελίδα
politiki-aporritou/        Πολιτική Απορρήτου
oroi-chrisis/              Όροι Χρήσης
assets/css | js | img      Στυλ, σενάρια, εικόνες
```

## Από πού παράγεται

Το πραγματικό site είναι **WordPress** και ζει στο έργο `psychologist-site`.
Επειδή το GitHub Pages σερβίρει μόνο αρχεία και δεν τρέχει PHP, ο φάκελος
αυτός παράγεται αυτόματα από το WordPress:

```bash
cd ../psychologist-site
docker compose up -d          # ξεκίνα το WordPress
npm run export                # ξαναφτιάξε αυτόν τον φάκελο
```

**Μην αλλάζεις τα αρχεία εδώ με το χέρι** — θα σβηστούν στην επόμενη εξαγωγή.
Οι αλλαγές γίνονται στο θέμα του WordPress.

## Ραντεβού

Το site δεν έχει δική του φόρμα. Όλα τα κουμπιά «Κλείστε Ραντεβού» οδηγούν
στο προφίλ του ψυχολόγου στο doctoranytime, όπου γίνεται η κράτηση. Έτσι η
στατική έκδοση λειτουργεί ακριβώς όπως και το κανονικό site — δεν χρειάζεται
server για τίποτα.
